
# 🏆 Scoreboard กิจกรรมสานสัมพันธ์ (ศาลเด็กประจวบเกมส์)

ระบบสกอร์บอร์ดกีฬาดิจิทัลแบบเรียลไทม์ (Real-time Digital Scoreboard) ที่ดึงข้อมูลคะแนนโดยตรงจาก Google Sheets ออกแบบมาให้มีความทันสมัย รองรับการแสดงผลทั้งโหมดมืดและโหมดสว่าง พร้อมเอฟเฟกต์โต้ตอบที่สนุกสนาน

## ✨ ฟีเจอร์เด่น (Key Features)

* **⚡ Real-time Updates:** อัปเดตคะแนนทันทีที่แก้ไขใน Google Sheets (ไม่ต้องรีเฟรชหน้าเว็บ)
* **🎨 Dynamic Themes:**
    * **Dark Mode:** พื้นหลัง Gradient น้ำเงินเข้ม-ดำ สุดพรีเมียม พร้อมการ์ดโปร่งแสง
    * **Light Mode:** พื้นหลังโทนขาว-ฟ้า สะอาดตา อ่านง่าย
* **🐷 Fun Visuals:**
    * **ผู้นำ (Leader):** แสดงสัญลักษณ์มงกุฎ 👑
    * **ผู้ตาม (Last Place):** แสดงอนิเมชันน้องหมูเด้งดึ๋ง 🐷 สร้างสีสันให้การแข่งขัน
* **📐 Auto-Layout Grid:** ปรับหน้าจออัตโนมัติ
    * ถ้ามี **2 ทีม**: ขยายการ์ดใหญ่แบ่งครึ่งจอ
    * ถ้ามี **3-4 ทีม**: แบ่ง 4 ช่องตามปกติ
* **🌈 Team Color Tint:** การ์ดคะแนนจะเปลี่ยนสีพื้นหลังจางๆ (Glassmorphism) ตามสีประจำทีม (ม่วง, แดง, เหลือง, น้ำเงิน, ฟ้า)
* **📝 Dynamic Title:** ชื่อกีฬาด้านบน (เช่น "เปตอง", "แชร์บอล") เปลี่ยนตามข้อมูลใน Sheet ช่อง A1 โดยอัตโนมัติ

## 🛠️ การติดตั้งและใช้งาน (Setup)

### 1. เตรียม Google Sheet
สร้าง Google Sheet ใหม่ และจัดเรียงข้อมูลดังนี้:

|   | A (ชื่อทีม) | B (คะแนน) | C (สีทีม) | D (ประวัติรอบ 1) | E (ประวัติรอบ 2) | ... |
|---|---|---|---|---|---|---|
| **1** | **ชื่อกีฬา (เช่น เปตอง)** |   |   |   |   |   |
| **2** |   |   |   |   |   |   |
| **3** | ทีมสีม่วง | 13 | purple | 5 | 8 | ... |
| **4** | ทีมสีแดง | 9 | red | 4 | 5 | ... |
| **5** | ทีมสีเหลือง | 7 | yellow | 2 | 5 | ... |
| **6** | ทีมสีน้ำเงิน | 11 | blue | 6 | 5 | ... |

* **Cell A1:** ใส่ชื่อกีฬาที่จะแข่ง (ระบบจะดึงไปแสดงเป็นหัวข้อตัวอักษรสีทอง)
* **Column C (Color):** รองรับค่า: `purple`, `red`, `yellow`, `blue`, `cyan` (หรือภาษาไทย: `ม่วง`, `แดง`, `เหลือง`, `น้ำเงิน`, `ฟ้า`)
* **การแชร์:** ต้องตั้งค่า Share เป็น **"Anyone with the link" (ทุกคนที่มีลิงก์) -> Viewer**

### 2. ตั้งค่าไฟล์ Config
เปิดไฟล์ `config.js` และแก้ไขค่า `SHEET_ID` ให้ตรงกับ Sheet ของคุณ:

```javascript
const CONFIG = {
    // ไอดีจาก URL ของ Google Sheet
    SHEET_ID: 'YOUR_GOOGLE_SHEET_ID_HERE', 
    
    // ชื่อแท็บด้านล่าง (ปกติคือ Sheet1 หรือ Admin)
    SHEET_NAME: 'Sheet1', 
    
    // ความเร็วในการดึงข้อมูล (2000 = 2 วินาที)
    REFRESH_RATE: 2000 
};

```

### 3. เริ่มใช้งาน

เพียงเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ (Google Chrome, Edge, Safari) ก็พร้อมใช้งานทันที หรืออัปโหลดขึ้น Hosting เช่น Netlify / GitHub Pages

## 📦 โครงสร้างไฟล์

```text
├── index.html      # หน้าเว็บหลัก (UI/Logic)
├── config.js       # ไฟล์ตั้งค่าการเชื่อมต่อ
└── README.md       # คู่มือการใช้งาน

```

## 🎨 เทคโนโลยีที่ใช้

* **HTML5 / CSS3**
* **Tailwind CSS** (Utility-first CSS framework)
* **Animate.css** (Animation Effects)
* **Google Visualization API** (ดึงข้อมูล JSON จาก Sheet)
* **Vanilla JavaScript** (ทำงานรวดเร็ว ไม่ต้องติดตั้งอะไรเพิ่ม)
