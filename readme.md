# 🏆 Scoreboard กีฬาสานสัมพันธ์ (ศาลเด็กประจวบเกมส์)

สกอร์บอร์ดดิจิทัลแบบ Real-time ดึงข้อมูลจาก Google Sheets

## ✨ ฟีเจอร์หลัก
- **เปลี่ยนสีทีมได้ 4 สี:** ม่วง (Purple), แดง (Red), เหลือง (Yellow), น้ำเงิน (Blue)
- **เปลี่ยนชื่อกีฬาอัตโนมัติ:** แก้ที่หัวตาราง Google Sheet (Cell A1)
- **แสดงอารมณ์:**
  - 👑 **ผู้นำ:** โชว์มงกุฎ
  - 😭 **ผู้ตาม:** โชว์หน้าร้องไห้ (Animation สะอื้น)
- **โหมดแสดงผล:** รองรับทั้งโหมดมืด (Neon) และโหมดสว่าง (กลางแจ้ง)

## 🛠️ วิธีการใช้งาน
1. **แก้ไฟล์ `config.js`:** ใส่ Sheet ID ของคุณ
2. **ตั้งค่า Google Sheet:**
   - **Cell A1:** ใส่ชื่อกีฬา (เช่น "เปตอง")
   - **Col C:** ใส่สีทีม (purple, red, yellow, blue)
3. **เปิดไฟล์ `index.html`:** ใช้งานได้ทันที

---
**หมายเหตุ:** อย่าลืมตั้งค่า Google Sheet ให้ Share เป็น **"Anyone with the link can view"**
